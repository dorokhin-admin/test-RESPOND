# Анализатор конверсионности страниц

Минимальный рабочий прототип сервиса для анализа конверсионности страницы по структурированной методике.

## Как запустить

1. Установите зависимости:
   npm install
2. Запустите сервер:
   node server.js
3. Откройте браузер по адресу:
   http://localhost:3000

## Что реализовано

- Приём публичного URL
- Сбор HTML, текста, базовых метаданных и скриншотов
- Структурированная методика оценки по чек-листу
- Генерация отчёта с таблицей по блокам, списком проблем и беклогом задач
- Сохранение результатов анализа в JSON и HTML
- Понятные сообщения об ошибках

## Примечание

Для работы через LLM нужен ключ OpenAI в переменной окружения OPENAI_API_KEY. Без него сервис использует локальную оценку по зафиксированной методике и всё равно формирует отчёт.
